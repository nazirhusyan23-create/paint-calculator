# Traffic & Backlink Playbook — PaintCalc

## ⚠️ Important warning first

Search results are full of "300+ free directory submission sites" lists. **Avoid these almost entirely.**
Mass-submitting to low-quality, unrelated directories is exactly the pattern the tutorial warned about
("Wrong Links In → Penalty Out"). Google's algorithms specifically devalue (and can penalize) sites with
large numbers of low-quality, irrelevant backlinks. Quality over quantity — a handful of real,
relevant links beats hundreds of directory spam links every time.

## Part 2 — Reddit / Quora Answer Templates

**Golden rule: answer the actual question first, in your own words. Link goes at the end, framed as "I built this" — never as the whole answer.**

### Template A — Room paint quantity question
> For a room that size, you're generally looking at [X] gallons per coat if you're using standard coverage (350 sq ft/gallon) — don't forget to subtract your doors and windows or you'll overbuy. Two coats is standard unless you're doing a same-color touch-up.
>
> I actually built a free calculator for exactly this if you want an instant number instead of doing the math by hand: [link]

### Template B — Wallpaper quantity question
> Roll coverage depends on your pattern repeat — a plain/textured paper wastes about 10%, but a large pattern repeat can waste 20%+ since you have to match seams. Standard single rolls are about 56 sq ft before waste.
>
> If it helps, I put together a free calculator that factors in the repeat automatically: [link]

### Template C — Paint cost / budgeting question
> Rough numbers: a gallon of decent quality paint runs $30-50, and most rooms need 2-3 gallons for two coats. If you're hiring it out, labor is usually $1.50-3.50 per sq ft of wall on top of materials.
>
> I built a free calculator that adds up materials + labor into one total if you want to plug in your own numbers: [link]

### Template D — "What sheen should I use" question
> Depends on the room — eggshell for living areas/bedrooms, satin for kitchens/bathrooms/hallways (more washable), semi-gloss for trim and doors. Matte hides wall flaws best but scuffs easily.
>
> I wrote up a full breakdown with a room-by-room reference if it's useful: [link to article-paint-finish-guide]

### Posting discipline (don't get banned)
- **1 self-promotional comment per 8-10 genuine, link-free comments** on that subreddit
- Never post the same templated answer word-for-word repeatedly — always adapt to the actual question
- Read each subreddit's rules first — some ban tool/calculator links entirely, some have a dedicated weekly "self-promo" thread — use that instead of a regular post
- If a mod removes your post/comment, don't repost immediately elsewhere — it's a signal to slow down
